## 首年 $24.99，第二年还是这个价吗

这是选香港 VPS 最容易被忽略的一项。四家商家的续费承诺强度完全不同，不能统一说成“都不涨价”。

## 下单前要过的五道关

**库存和限购**。Lightlayer 双十一的香港独服只放 20 台，洛杉矶 30 台，特价云服务器每款限量 50 台，卖完就没了。同一活动还规定每个产品每个客户限购 2 台，下单后 1 小时内未支付订单会被取消。抢限量机型的时候，付款慢一步就白排。

**IP 类型**。Lightlayer 香港 $24.99 那款标的是“1 个非原生 IPv4”。做普通建站、跑 API 没问题，需要原生 IP 注册海外账号、做流媒体解锁的，这款不满足。

**库存之外的限购**。野草云香港轻量 VPS 每个账户限 3 台，超出就下不了单。弘速云香港 4核4G 年付 145 元那款只开放 10 个库存，售完即止。

**一次性费用**。野草云面向海外应用的那款 2核1G/300Mbps/1000G，118 元/年之外另收一次性初装费 10 元。低价的套餐经常藏这种小额附加费。

**地区限制和线路公告**。弘速云页面自述“当前禁美国及东南亚 IP 访问”，用海外网络下单或管理会受影响。弘速云的美国 9929 线路要在每月月初 IP 宣告流程完成后才恢复，买之前得看线路状态公告。这类限制不会写在价格表里，只写在页面角落。

退款政策也要提前确认。Lightlayer 只对商家自身原因造成的问题受理退款，常规价产品和促销产品都不退。这条比“7 天无理由”严格得多，买之前想清楚配置够不够用。
